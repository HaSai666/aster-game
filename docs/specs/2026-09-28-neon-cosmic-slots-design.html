ASTER GAME / PRODUCT DESIGN / 2026-09-28

霓虹宇宙老虎机

面向手机与桌面的 5 轴虚拟金币解压小游戏。玩家买入一笔金币后连续旋转，利用 243 Ways、星核能量和超新星免费旋转获得密集的视觉、音效与特效反馈。

5×3 轴盘243 Ways虚拟金币PixiJS / WebGLGitHub Pages无真钱入口

本规格是实现前的产品与技术设计；运行时无后端、支付或真钱兑换，并支持重置本地存档。

方案循环体验架构验证

01 / 方案决策

备选 A

原生静态页 + Canvas

轻量、无依赖，但底层动画维护量较高。

已选择 B

PixiJS / WebGL 视觉层

PixiJS 驱动轴、图标、粒子和镜头效果，HTML/CSS 管理控件与文本；首版用 CDN 直接加载，保持静态入口可部署。

备选 C

React / Vite

扩展友好，但当前单页游戏的状态层偏重。

边界：纯单机、纯虚拟币，无账号、联网匹配、支付、提现或兑换；GitHub Pages 只托管静态文件。后续需要拆分模块时，可在不改变规则接口的前提下引入构建工具。

02 / 核心游玩循环

  1. 选择 1,000 / 3,000 / 10,000 虚拟金币带入本局。
  2. 选择 10 / 25 / 50 / 100 下注，手动、快速或自动旋转。
  3. 5×3 盘面从最左轴检查相邻连续图标；每轴数量相乘得到 Ways。
  4. Wild 替代普通图标；Scatter 触发免费旋转；星核只增加能量。
  5. 每旋转基础 +1 能量，星核额外 +1–3；累计 18 格必定触发超新星。
  6. 超新星给 8 次免费旋转，至少 2 倍倍率，可延长一次；玩家随时收手。

04 / 架构与数据流

模块

  • GameState：余额、下注、能量、免费旋转和阶段。
  • SpinEngine：轴结果、243 Ways、赔率和奖励。
  • PixiStage：轴、图标、粒子、镜头和缩放。
  • EffectTimeline：表现时序。
  • AudioEngine：Web Audio。
  • UiShell：HTML 控件和可访问文本。
  • SaveStore：版本化 localStorage。

状态

IDLE → SPINNING → EVALUATING → PRESENTING_WIN → BONUS → IDLE

每次旋转有唯一 spinId；先完整结算，再播放表现，避免重复扣款或派奖。

UiShell → GameState → SpinEngine
                ├→ EffectTimeline → PixiStage
                ├→ AudioEngine
                └→ SaveStore

WebGL 失败时用 DOM/CSS 轴动画；音频被阻止时保持可玩；切后台暂停；reduced-motion 关闭震动、闪白和高密度粒子。

06 / 质感与桌面布局优化

盘面图标不使用字符占位，PixiJS 以矢量图形绘制彗星、行星、月环、星云、星辰、王冠、Wild、星门和星核；每个符号包含发光核心、轨道、材质高光和命中环。旋转时启用运动模糊、错峰停轴、停轴脉冲和舞台扫描光，中奖时叠加镜头震动、粒子、冲击环和数字爆发。

桌面端采用左侧主机、右侧控制台的首屏布局：顶部 HUD 横跨全宽，左侧盘面纵向填充，右侧依次放置下注/旋转控制、超新星状态、星际记录和成就。常见桌面高度下禁止页面滚动；手机端恢复纵向滚动与单列布局。

07 / 验证标准与范围

自动化

  • 243 Ways、Wild、Scatter、星核、免费旋转。
  • 余额不为负；spinId 不重复扣款或派奖。
  • 快速/普通结果一致；自动旋转正确暂停。
  • 首次存档、迁移、损坏和重置。

人工验收

  • 桌面、窄手机、横竖屏。
  • WebGL 降级仍可旋转结算。
  • 音频解锁、静音、后台切换。
  • 大奖完整播放且无支付入口。
